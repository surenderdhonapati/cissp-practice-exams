# Changelog

Every change to the item banks is listed here by item id and date. A bank change is any correction to a stem, an option, a key or an explanation that affects the answer. Wording fixes that do not change the tested concept are batched in the version notes. The version and the build date are shown on the start screen of every exam file.

## Version 1.1, 2026-11-13

No item changed. Every exam file now asks for a tip (Ko-fi, PayPal and UPI) on the start screen, on the result page together with the UPI code, and in a footer line. The README has a support section with the same details and the repository shows a Sponsor button that points to Ko-fi and PayPal. Since 1.0 the README, the start page and the exam files also state that this is a personal project, not connected to any employer.

## Version 1.0, 2026-11-10

First public release. Four adaptive exams, 150 items each, 600 items in all, written on the ISC2 CISSP exam outline across all eight domains. Exams A and B untimed with explanations after every answer, exams C and D timed at 180 minutes with three pauses per attempt.
